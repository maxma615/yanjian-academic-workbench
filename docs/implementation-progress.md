## 已实现

- 七个页面：概览、待办、月历、文献、Markdown 笔记、同日多篇研究日志、资料与设置。支持编辑、删除、文献关联、检索和导出。
- 本地 PDF 导入、多个附件、浏览器打开和下载；缺少本机附件时明确提示。
- Markdown/JSON/PDF 为主存储，UUID 与修订号标识记录。SQLite 可重建，索引失败不回滚已经保存的资料；显示待重建状态。
- 单写实例锁、提交前锁身份复验、并发修订冲突保留输入。第二实例可阅读全文及导出，只读时禁用编辑、恢复和完整备份。
- 删除快照与墓碑；日志跨年移动恢复。旧日志因权限无法删除时保留两份文件，展示已验证的新版本并进入只读，显示待处理路径；移除旧文件后重开可恢复编辑。
- SHA-256 清单完整备份，排除凭据、缓存和派生索引。恢复先验证归档、文件、领域关联和索引，再提交到绑定 token 的独立空目录，最后持久化切换活动目录。
- 迁移模块支持夹具转换、持久化迁移前备份、源变更检测、迁移锁及中断恢复。首版生产格式为 v1，没有虚构已发布旧版本或提供未经验证的自动升级入口。
- 默认按 Asia/Shanghai 显示时间，纯日期不随设备时区漂移；支持全天、带时间和跨天日程。

端到端测试启动真实生产服务，使用生成的有效单页 PDF 与中文测试资料；阻断主流程所有非 loopback 请求。经 UI 创建文献、导入 PDF、关联笔记、同日两篇日志、待办、全天及跨天日程，停止并重启进程后读取实际文件。Markdown 导出与原文件字节相同；完整备份恢复逐项比较文件字节，恢复后重启并再次导出 PDF，字节与原附件一致。

另验证两个页面编辑同一记录时旧修订不能覆盖新内容，未保存输入仍在；第二进程只读时可阅读全文及导出；620px 窗口可导航、完成/删除任务和重建索引。桌面与窄窗截图均实际打开检查，证据在 `test-results/research-loop.png`、`test-results/narrow-window.png`（后续测试会更新）。

测试过程中发现并修复：事件表单格式不匹配、只读记录无法打开、空可选字段被错误拒绝、恢复关联误把任务当文献、跨端口 Cookie 相互覆盖、锁被另一实例接替后的旧提交、跨年移动的权限失败、迁移 journal 安全边界和窄窗卡片溢出。详细断言见对应测试文件。

## 范围和后续

- 本轮是可运行的本地 Web 开发适配器。Electron 安装包、Windows 11 原生目录/保存对话框、系统默认 PDF 程序、卸载重装及具体架构兼容性仍为 `NOT_RUN`。
- 认证后的开发 UI 明确填写空目录，再由服务校验身份并签发一次性 token。当前没有任意文件读写 API。Node 路径检查仍不能完全消除同用户在检查与打开之间制造的原生目录替换竞态；Windows junction/reparse point/句柄级保护须在原生适配中继续验证。
- 自动化覆盖不替代真实 Windows IME、断电、跨卷、权限变更和所有崩溃时间点验收。矩阵中复合用例保留 `PARTIAL` 或 `NOT_RUN`。
- GitHub 同步未实现、保持关闭；待本地功能稳定后再按明确私人仓库目的地和授权开展。
- 开发配置、依赖、缓存、夹具和产物均位于本应用目录；生产启动默认使用系统应用数据目录。未创建根 Git/包配置，未操作情侣小屋文件、服务或数据，未发布远端制品。
